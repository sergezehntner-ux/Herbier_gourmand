# Herbier Gourmand v2.9.7.15 — Regroupement des courses

Base : v2.9.7.14 validée.

- Regroupe et additionne les ingrédients identiques lors de transferts successifs depuis le Planning.
- Harmonise les unités compatibles : kg/g, l/ml et variantes usuelles de pièce.
- Conserve les différentes recettes sources d’un article regroupé.
- Ne fusionne pas les articles ajoutés manuellement avec ceux générés par le Planning.
- Corrige aussi le retrait d’un ancien transfert afin qu’il ne touche jamais un article manuel du même nom.

Aucune donnée n’est fournie ni remplacée.
