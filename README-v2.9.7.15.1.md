# Herbier Gourmand v2.9.7.15.1 — Regroupement simple des courses

Base : v2.9.7.14 stable.

Modification unique : lors d’un transfert depuis le Planning, deux lignes générées par des recettes sont regroupées uniquement si le nom de l’ingrédient et l’unité correspondent. Les quantités sont additionnées et les recettes sources restent mémorisées. Les articles ajoutés manuellement restent indépendants.

Aucune conversion d’unités (kg/g, l/ml) n’est effectuée dans cette version.

Remplacer sur GitHub : `index.html`, `app-v282.js`, `version.json`, `manifest.webmanifest`, `sw.js`, `service-worker.js`.
