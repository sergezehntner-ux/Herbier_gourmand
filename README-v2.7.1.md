# Herbier Gourmand v2.7.1 — Corrections terrain prioritaires

Cette version conserve toutes les données et fonctions de la v2.7 et ajoute :

- maintien de l’écran allumé dans **Courses** et **Voir la recette** lorsque le navigateur prend en charge l’API Wake Lock ;
- remise à zéro complète du planning avec **Vider** : repas, créneaux, temps et personnes ;
- correction du risque de créneau résiduel lors d’une nouvelle planification ;
- cartes restaurants compactes sur deux lignes, avec horaires et spécialités ;
- suppression des tags producteurs affichés en double ;
- libellé et filtre **Lieu** pour les producteurs ;
- affichage du code postal et du lieu sur une seule ligne ;
- suppression de leur répétition lorsque l’adresse les contient déjà ;
- nouveau cache PWA `herbier-v2-7-1`.

Les évolutions de confort plus lourdes (recherche « sans », plusieurs recettes par repas, personnes par créneau, préparation la veille) sont reportées.
