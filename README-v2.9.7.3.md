## Fonction
Après avoir marqué un repas « Cuisiné », le bouton « Utiliser des restes » permet :
- d'indiquer le nombre de portions disponibles ;
- de choisir « complément » ou « repas » ;
- de choisir une idée de réutilisation, une date ultérieure et Matin/Midi/Soir ;
- pour un repas déjà occupé, de remplacer l'existant ou d'ajouter les restes ;
- de ne jamais ajouter automatiquement les ingrédients des restes aux Courses ;
- d'ajouter seulement une remarque « À vérifier — utilisation de restes » dans Courses ;
- en cas de remplacement, de retirer des Courses le transfert du repas remplacé.

Aucun fichier JSON de données n'est remplacé.
