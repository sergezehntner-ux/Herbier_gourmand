# Herbier Gourmand v2.9.7.8 — Choix tactiles

Correctif ergonomique ciblé pour les champs à suggestions.

## Modifications
- Les champs HTML reliés à une liste de suggestions affichent maintenant une liste tactile propre sous le champ.
- Sur smartphone, il suffit de toucher une proposition pour la valider : aucune touche Tab n’est nécessaire.
- Sur notebook, clic, Entrée et Tab restent utilisables.
- Pour le champ Tags, la suggestion complète uniquement le dernier tag après la virgule.
- Aucun fichier de données n’est modifié.
