# Herbier Gourmand v3.0.71

- Recettes : correspondance exacte des noms d’ingrédients ou identifiants Catalogue, sans associations culinaires indirectes.
- Taille et espacement des boutons de recettes réduits.
- Techniques : filtrage par références explicites au produit, et affichage compact. Les techniques génériques sans lien explicite ne sont plus proposées.
- Vue : tableau pleine largeur ; boutons repositionnés à gauche de la photo.

Remarque : les variantes d’ingrédients non normalisées dans les recettes peuvent nécessiter une harmonisation manuelle avec le Catalogue.
