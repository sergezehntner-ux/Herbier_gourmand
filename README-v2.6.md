# Herbier Gourmand v2.6 — Envie d’une sortie ?

- Nouvelle rubrique Restaurants / Sorties.
- 160 restaurants importés depuis Restaurants.vcf.
- Recherche croisée par nom, lieu, pays et spécialité.
- Création, consultation plein écran, modification, duplication et suppression.
- Fiches : nom, tenancier, adresse, code postal, lieu, pays, téléphone, site, heures d’ouverture, spécialités et remarques.
- Restaurants inclus automatiquement dans les sauvegardes `.hgbak`.
- Toutes les fonctions v2.5.1d sont conservées.

## Installation
Sauvegarder les données actuelles, remplacer les fichiers du dépôt par ceux de cette archive, puis attendre GitHub Pages et actualiser l’application.
