# Herbier Gourmand v2.9.7.4 — Ergonomie Restes

Base : v2.9.7.3, elle-même issue de la v2.9.7.1 stable.

Corrections ciblées :
- « Utiliser des restes » n'utilise plus de lettres/mots à saisir : choix par boutons.
- Quantité : boutons 1 à 10 portions.
- Type : boutons « Comme complément » / « Comme repas ».
- Idée de restes : boutons si plusieurs idées existent.
- Date : vrai sélecteur calendrier natif.
- Repas : boutons Matin / Midi / Soir.
- Un créneau vide peut recevoir les restes comme repas.
- Si « complément » est choisi sur un créneau vide, Herbier propose soit de convertir les restes en repas, soit de choisir un autre créneau.
- Sur un créneau occupé : boutons « Ajouter les restes » / « Remplacer le choix existant ».

Aucun fichier de données n'est inclus ni remplacé.
