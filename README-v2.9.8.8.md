# Herbier Gourmand v2.9.8.8 — Tableau Excel des recettes

- Export des recettes vers un tableau CSV UTF-8 compatible Excel.
- Une ligne par recette, avec ID technique stable.
- Colonnes modifiables : Catégorie, Saison, Type, Effort, Difficulté, Spécial, Température, Portions, Tags.
- Titre exporté pour repérage mais volontairement non réimporté.
- Réimport sécurisé par ID : aucune création ni suppression de recette.
- Ingrédients, préparation, photos, source, notes et mémoire culinaire sont conservés.
- Aperçu du nombre de recettes reconnues, changements, valeurs invalides et identifiants inconnus avant confirmation.
- Sauvegarde .hgbak recommandée avant un import massif.
